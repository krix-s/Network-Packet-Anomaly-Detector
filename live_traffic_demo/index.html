What the processing means

Each one-second bin produces packet count, total bytes, and mean packet inter-arrival time. The pipeline applies log1p for dynamic-range compression, then a causal EWMA low-pass filter. The difference between the compressed signal and its smoothed value is the high-frequency residual. The CNN reconstructs windows of the smoothed signal plus residual; a large reconstruction error means “unusual compared with this baseline.”

Interpretation: this is an anomaly score, not an attack label. Simulation mode uses generated traffic patterns. Live mode learns a baseline from the selected interface; capture results are not validated attack-detection accuracy.

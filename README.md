# Network Traffic Anomaly Detection

Network traffic anomaly detection using machine learning and
deep learning techniques, with a focus on temporal network traffic
patterns.

## Dataset

NF-CSE-CIC-IDS2018

## Project Status

Initial setup and dataset exploration.

## Goals

- Understand network traffic data
- Build classical ML baselines
- Investigate temporal representations
- Develop a 1D CNN for network traffic classification
- Evaluate robustness and generalization
- Eventually investigate real-time network traffic detection

Network traffic, made understandable

Can a computer spot a suspicious connection?

This project learns patterns from short summaries of network connections. Choose a recorded example and see how two models decide whether it looks like an attack and, if so, what kind.

A simple way to think about it A flow is like a receipt for a conversation between computers: how long it lasted, how many bytes moved, and a few other technical details. The model reads that receipt, not the private message itself.

A good result still has limits

The model is strongest on common patterns in this dataset. Rare SQL Injection examples remain difficult: it missed all 65 SQL Injection flows in the sampled test set. These scores do not guarantee safety on another network. The category scores are model confidence estimates, not calibrated probabilities.

FlowWatch is an educational demonstration of flow-based network anomaly detection. It uses precomputed examples and is not a live monitoring or incident-response system.
